# IDs de APIs consultados para o Worker

Valores conferidos com documentação oficial consultada em 2026-10-25. Não coloque chaves reais neste arquivo.

- **xAI TTS:** endpoint `POST https://api.x.ai/v1/tts`. A documentação consultada exige `text` e `language` e não usa campo `model`; portanto, a integração não inventa um ID `grok-tts` na requisição. Fontes: [TTS](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech), [modelos TTS](https://docs.x.ai/developers/models/text-to-speech).
- **ElevenLabs Flash/Turbo/v3:** endpoint padrão TTS e IDs `eleven_flash_v2_5`, `eleven_turbo_v2_5` e `eleven_v3`. Turbo v2.5 é marcado como versão antiga/depreciada em favor de Flash; a disponibilidade deve ser validada na conta. Fontes: [modelos](https://elevenlabs.io/docs/overview/models), [TTS convert](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).
- **ElevenLabs Music v2:** endpoint `POST /v1/music`, `model_id: music_v2`. Fonte: [Compose Music](https://elevenlabs.io/docs/api-reference/music/compose).
- **Pruna P-Video:** `Model: p-video`; **Animate:** `Model: p-video-animate`; **Avatar:** `Model: p-video-avatar`; endpoint `POST https://api.pruna.ai/v1/predictions`, credencial no header `apikey` e corpo `{ input: ... }`. Fontes: [P-Video](https://docs.api.pruna.ai/guides/models/p-video), [P-Video Animate](https://docs.api.pruna.ai/guides/models/p-video-animate), [P-Video Avatar](https://docs.api.pruna.ai/guides/models/p-video-avatar).
- **Bria FIBO:** documentação atual consultada usa `POST /v2/image/generate` e `POST /v2/image/edit`, header `api_token`, família Fibo. Não achei um ID público exato `FIBO 1.5`; o código chama a API atual e não finge fixar essa versão. Fontes: [Generate Image](https://docs.bria.ai/image-generation/generation/image-generate), [Edit Image](https://docs.bria.ai/image-editing/v2-endpoints/edit-image), [Quickstart](https://docs.bria.ai/getting-started/quickstart).
- **MiniMax H3 Max:** `POST https://api.minimax.io/v2/video_generation`, campo `model: MiniMax-H3-Max`, corpo com `content`, `resolution`, `duration`; H3 Max aceita `480P` e `768P`, não 2K. Fontes: [Create Video Generation Task](https://platform.minimax.io/docs/api-reference/video-generation-v2-create), [vídeo](https://platform.minimax.io/docs/guides/video-generation).

O arquivo `worker.js` preserva os nomes e valores internos do catálogo de venda do portal. Essa tabela é de preço ao usuário e não prova equivalência com custo upstream, versão contratada nem saldo/entitlement da conta de cada provedor. Faça um teste de fumaça com cada secret de API e os inputs de produção antes de habilitar vendas reais.
